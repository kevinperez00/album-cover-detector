# album-cover-detector
Image detection project that detects album covers and plays corresponding YouTube videos

This project uses OpenCV to detect album covers through a webcam and Selenium to open the corresponding YouTube video

## Requirements
- Python
- Google Chrome
- Webcam

## Installation
pip install -r requirements.txt

## Running the Program
pyhton main.py

Press Q to exit the program (you have to have the webcam popup selected for it to close with Q)
